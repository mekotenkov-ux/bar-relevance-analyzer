# Отложенный LLM-эксперимент семантических триплетов

Статус: **отложен 14 августа 2026 года**.

Компактная локальная LLM оказалась недостаточно стабильной для основного
алгоритма триплетов. Код сохранён как воспроизводимый эксперимент, но не является
движком BAR по умолчанию и не должен запускаться из-за оставшихся в окружении URL,
токенов или имён моделей.

## Защита от случайного запуска

Веб-адаптер вызывает этот путь только при одновременном выполнении двух условий:

1. пользователь отдельно включил построение связей в отчёте;
2. оператор сервера явно установил `TRIPLET_ENGINE=llm`.

Переменные `TRIPLET_API_URL`, `TRIPLETS_SERVICE_URL`, `TRIPLET_MODEL` и ключи без
`TRIPLET_ENGINE=llm` не активируют эксперимент. Ollama и уже загруженные модели
можно оставить установленными: BAR их не вызывает автоматически.

## Содержимое

- адаптер BAR и API-маршрут;
- прямой OpenAI-совместимый путь для Ollama;
- отдельный FastAPI-адаптер для NuExtract/llama.cpp;
- Docker-конфигурация, безопасный пример окружения и Modelfile;
- проверки лимитов, привязки результата к исходным предложениям и opt-in;
- MIT-лицензия и файлы авторства проекта.

В архив намеренно не входят `.env`, `.env.local`, API-ключи, пользовательские
данные, веса моделей, Docker volumes, `node_modules`, сборка и Python-кэши.

## Пересборка архива

Из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\experiments\triplets-llm\package.ps1
```

Скрипт использует закрытый фиксированный список исходников, сортирует записи,
ставит им одинаковое время и добавляет `ARCHIVE-MANIFEST.sha256`. Поэтому архив
можно проверить и пересобрать без копирования секретов или весов модели.

Результат: `artifacts/triplets-llm-deferred.zip`.

## Осознанный повторный запуск

Инструкции для Ollama и CPU-сервиса сохранены в
`services/triplets/README.md`. При повторном эксперименте добавьте в локальный,
игнорируемый Git файл окружения:

```dotenv
TRIPLET_ENGINE=llm
```

После завершения опыта удалите эту строку или установите другое значение. Новые
детерминированные реализации spaCy/Stanza не должны переиспользовать LLM opt-in.
