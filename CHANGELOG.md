# Changelog

Значимые изменения проекта будут фиксироваться в этом файле. После появления
первого tag проект будет использовать Semantic Versioning, насколько это возможно
для pre-release продукта.

## [Unreleased]

### Added

- self-hosted/open-source руководство в README;
- community-документы для вкладов, поддержки, безопасности и поведения;
- GitHub issue и pull request templates;
- сводка прямых сторонних компонентов и внешних интеграций.
- GitHub Actions CI, отдельные typecheck и Python syntax checks;
- архитектурная схема, инструкция первой GitHub-публикации и social preview БАР.
- локальный CPU-сервис Multilingual E5, пакетный API, LRU-кэш и живой diagnostic
  «курсы SEO»;
- snapshot-кэш сходства N-грамм и безопасный fallback при недоступном E5.
- нормирование ориентиров лемм и N-грамм под объём своей страницы и каждой
  HTML-зоны;
- позиционное объединение полностью вложенных фраз без потери самостоятельных
  вхождений;
- Markdown-ТЗ для страницы, сортировки таблиц и человекочитаемый справочник
  регионов XMLRiver.
- единый реестр языков, RU/EN/ES пресеты стоп-термов, script-aware
  автоопределение и регрессионные тесты мультиязычной морфологии;
- многословные элементы встроенных локализованных стоп-листов теперь
  сопоставляются как последовательности, а не как недостижимые одиночные слова.
- связанный выбор страны и города/региона с серверной фильтрацией полного
  справочника XMLRiver.
- словарная русская лемматизация Az.Morph с регрессией для форм «месяц»,
  «академия» и нерегулярных прилагательных.

### Changed

- пользовательская установка, production-настройка и правила для AI-агентов
  объединены в один канонический README без дублирующей инструкции;
- обновлены React/RSC, Vinext, Vite, Cloudflare plugin и Wrangler;
- XMLRiver credentials перенесены из постоянного browser storage в данные
  текущей вкладки;
- конфигурация проекта отвязана от частного Sites project ID.
- Firecrawl fallback теперь автоматически включается при наличии серверного
  ключа; пользовательский переключатель удалён, статусы XMLRiver и Firecrawl
  перенесены в поясняющие карточки рядом с соответствующими настройками.
- сходство N-грамм с ключами при подключённом сервисе переведено на
  `multilingual-e5-large-instruct`; распространённость у конкурентов и метрики
  документов сохранены независимыми.
- эксперимент семантических триплетов отключён и исключён из релизной сборки;
  локальные исходники сохранены отдельно для возможного продолжения работы.
- UI теперь честно различает Snowball-стемминг и токенизацию без склейки словоформ;
  ручные правки стоп-термов сохраняются отдельно для каждого выбранного языка.
- кнопки подключения скрываются после успешного подключения XMLRiver или
  Firecrawl; пользователь видит только актуальный статус интеграции.
- русский язык выбран по умолчанию, поля корпуса выровнены, а служебные подписи
  о родительской фразе удалены из таблицы тематических фраз и CSV.
- верхняя сводка сопоставляет три процентные метрики со средним значением
  принятых конкурентов; важные блоки, действия и колонки получили подсказки;
  раздел облаков переименован в «Облако», а описание важности лемм и N-грамм
  стало явным без раскрытия внутренних коэффициентов.
- в таблице N-грамм восстановлено морфологическое определение попадания фразы
  в ключ: точные формы помечаются «Ключ», семантически близкие — «Возможно ключ».

### Security

- добавлены рекомендации по BYOK, secret manager, квотам и очистке отчётов.
- Firecrawl и NLP secrets исключены из build vars и ожидаются только в runtime.
