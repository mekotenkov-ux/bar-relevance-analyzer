# Поддержка

БАР — open-source проект с поддержкой по мере доступности участников. Фиксированное
время ответа и персональная помощь не гарантируются.

## Куда обратиться

- **Ошибка или регрессия:** GitHub Issue по шаблону bug report.
- **Новая возможность:** GitHub Issue по шаблону feature request.
- **Вопрос по установке:** GitHub Issue или Discussions, если они включены.
- **Уязвимость:** только приватный процесс из [SECURITY.md](SECURITY.md).
- **Материалы SEO Мясо:** [seomeat.ru](https://seomeat.ru/) и
  [Telegram создателя](https://t.me/seokotenkov).

## Что приложить к техническому вопросу

- версия Node.js, ОС и commit/tag;
- локальный или production-режим;
- точная последовательность действий;
- ожидаемый и фактический результат;
- обезличенный короткий пример входа;
- безопасный фрагмент лога и HTTP status;
- используется ли XMLRiver, Firecrawl или spaCy.

Перед публикацией удалите API-ключи, cookies, персональные данные, приватные URL и
полный текст чужих страниц. Не прикладывайте `.env`, production snapshots и
необработанные сетевые дампы.

## Границы поддержки

Участники могут помочь с кодом репозитория и документированной self-hosted
конфигурацией, но не администрируют сторонние аккаунты XMLRiver/Firecrawl,
чужие reverse proxy, DNS, биллинг и условия использования анализируемых сайтов.
Fork с существенными изменениями сначала должен воспроизвести проблему на текущем
`main` либо предоставить минимальный patch, показывающий отличие.
